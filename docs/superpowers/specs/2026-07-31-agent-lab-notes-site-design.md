# agent-lab-notes 新手知识站设计

## 目标

将现有仓库建设为面向科研 Agent 新手的中文知识站。读者应能从零准备环境、选择一个 Agent、添加科研 Skills、配置 Zotero，并完成第一篇结构化文献笔记。

完成标准是生成一篇包含研究问题、方法、结论和待验证事项的文献笔记，而不是仅阅读若干教程。

## 信息架构

网站提供四个一级入口：

1. 首页
2. 新手路径
3. 知识库
4. 搜索

首页首屏使用“从零搭建科研 Agent 工具链，完成第一篇结构化文献笔记”作为核心说明，并提供“开始新手路径”和“浏览知识库”两个入口。

新手路径分为五步：

1. 根据操作系统准备 Git、Node.js 等必要环境。
2. 在 Codex 与 Claude Code 中选择一个完成安装。
3. 添加科研相关 Skills。
4. 配置 Zotero 文献整理工作流。
5. 先执行 `dry-run`，确认后生成结构化研究笔记。

知识库沿用仓库当前分类，供完成入门或需要解决具体问题的读者查阅。

## 页面设计

首页首屏采用左右结构。左侧放置站点名称、核心说明和两个主要入口；右侧展示五步路径概览。首屏下方依次展示入门路径、精选指南、知识库分类和最近更新。

文档页在桌面端使用分类导航、正文、文章目录三栏布局。移动端将导航和目录收进按钮，正文保持优先。正文限制阅读宽度，代码块、命令和安全提示需要清晰区分。

视觉采用米白背景、深色正文和蓝绿色强调色。页面依靠排版、留白和简单 CSS 图形建立层次，不使用无关插画或复杂动画。Codex 与 Claude Code 保持同等权重。

## 内容与数据流

网站在构建时读取仓库现有 Markdown，提取标题、分类和正文，生成文章页面与本地搜索索引，再发布到 Sites。

只收录根 `README.md` 已列出的公开指南。根 `AGENTS.md`、日期笔记、脚本和其他内部文件不自动公开。Markdown 是唯一内容源，不复制或改写现有教程正文。

首版支持标题、表格、代码块、图片和相对链接。搜索在浏览器本地完成，不上传查询内容。

## 异常处理

- 不存在的地址显示 404 页面，并提供返回知识库入口。
- 公开文档缺少一级标题、产生重复地址或包含失效站内链接时，构建失败。
- 外部链接异常不阻止构建，避免第三方网络状态影响发布。

## 首版边界

首版不包含登录、学习进度保存、评论、CMS、AI 问答、实时模型榜单和多语言切换。

## 验证

- 所有公开 Markdown 均能生成页面。
- 首页、新手路径、知识库、搜索和 404 页面可访问。
- 中文路径、截图、代码块、表格和相对链接正确显示。
- 键盘焦点、颜色对比与移动端排版满足基本可访问性要求。
- 完整部署构建成功后再发布私有 Sites 版本。
