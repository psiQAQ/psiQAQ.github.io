# 资源卡片、源码详情页与首页主题导航设计

## 目标

调整网站资源区的信息层级：`/resources` 只作为资源索引，所有条目以卡片展示；本地文本源码点击后进入独立页面阅读和复制，不再在索引页直接展开完整源码。同时将 Claude Code 的 Windows、macOS、Linux/WSL 三套启动脚本全部纳入 README 公开清单。

本次改动沿用现有 README 清单、`notes/` 目录和静态导出架构，不改变 Markdown 指南、全文搜索和现有 `/guides/...` URL。

首页同时做信息收敛：右侧知识库索引展示 README 的全部指南主题，删除与该索引重复的“精选指南”和“完整知识库”区块，保留首页主视觉和五步新手路径。

## README 清单

在 `智能体 → Claude Code` 分组中保留 `cc.bat`，并增加：

- `notes/agents/claude-code/ccmac.sh`：macOS 启动脚本；
- `notes/agents/claude-code/cclinux.sh`：Linux/WSL 启动脚本。

三个文件均使用普通 Markdown 链接和简短平台说明。网站继续只解析 `site-catalog` 标记之间的内容，README 的 `##` 分类、`###` 分组和条目顺序仍是网站唯一的资源编排来源。

## 资源索引页

`/resources` 严格按 README 的两级结构展示：

1. `##` 成为页面分类标题；
2. `###` 成为分类内分组标题；
3. 分组内资源按 README 出现顺序排列为卡片。

索引页不再包含完整源码。三类卡片行为如下：

| 类型 | 卡片内容 | 点击行为 |
| --- | --- | --- |
| 本地文本源码 | 文件名、平台或用途说明、文件类型 | 进入站内源码详情页 |
| 外部链接 | README 标题与说明 | 新标签页打开外部地址 |
| 下载文件 | 文件名与说明 | 直接下载构建产物 |

分类或分组中只有一种资源类型时不增加额外的“外链”“源码”等标题，避免重复层级。卡片继续复用现有边框、颜色、圆角和响应式网格。

## 源码详情页

本地文本源码使用物理文件的逻辑路径生成稳定地址，例如：

```text
notes/agents/claude-code/cc.bat
→ /resources/agents/claude-code/cc.bat
```

新增 catch-all 静态路由 `app/resources/[...slug]/page.tsx`，只为 README 已列出的 `source` 资源生成参数。详情页包含：

- 返回资源索引的面包屑；
- README 分类和分组；
- 以真实文件名为一级标题；
- README 简介；
- 文件类型标签；
- 完整、转义后的源码；
- 复制源码按钮及成功或失败状态。

不存在、未列入 README 或不是文本源码的 slug 返回 404。详情页不把下载文件或外部 URL 伪装成源码页面。

## 内容模型

保留现有 `ResourceRecord` 联合类型，只给 `source` 分支增加由 `sourcePath` 直接派生的站内 `slug`。增加一个按 slug 查找源码资源的只读函数，供详情路由复用；不建立新的清单文件、数据库或客户端路由状态。

资源索引按现有 `category` 和 `group` 字段分组。分类和分组数组均从 `resources` 的首次出现顺序派生，避免重新排序或维护第二套配置。

## 首页主题导航

首页右侧知识库索引继续显示公开指南数量和主题数量，其下方列表从四篇硬编码精选指南改为 `categories` 的完整主题列表。每个主题链接到 `/library#分类名`，顺序与 README 的 `##` 分类一致。

首页保留：

- 主标题、简介和两个主要按钮；
- 知识库索引及全部主题；
- “从安装到第一篇笔记”五步新手路径。

首页删除：

- “精选指南 / 新手最常用的四个入口”；
- “完整知识库 / 27 篇公开指南，按需查阅”。

删除这两个区块后，同步清理只为它们服务的 `featuredSlugs`、精选文档查找逻辑和无调用 CSS；不改变知识库、搜索或新手路径页面。

## 错误处理与公开边界

- README 中缺失的本地目标继续在构建时失败。
- 未列入 README 的脚本不生成资源卡片、详情路由或 Pages 客户端文件。
- 外部链接不在构建时联网检查。
- Markdown 图片继续只由指南渲染，不进入资源索引。
- 下载资源继续使用构建 URL 和原文件名，不进入源码详情页。

## 验证标准

自动验证覆盖：

- README 清单包含 `cc.bat`、`ccmac.sh` 和 `cclinux.sh`；
- `/resources` 按 README 分类、分组和顺序显示资源卡片；
- 索引页不再包含 `@echo off` 等完整源码；
- 三个 Claude Code 启动脚本卡片均指向对应站内详情页；
- 每个详情页显示文件名、完整源码和复制按钮；
- 未列出的源码文件仍不导出；
- 外部资源仍使用新标签页，搜索仍只包含 Markdown 指南；
- 首页知识库索引按 README 顺序展示全部主题并链接到对应知识库分类；
- 首页不再包含“精选指南”和“完整知识库”两个重复区块；
- `npm test`、`npm run lint`、静态导出和 `git diff --check` 通过。

远端推送与 GitHub Pages 部署在本地实现及完整验证通过后单独执行。
