# Fumadocs 风格知识库改造设计

## 目标

在不更换现有 Sites/vinext 架构、不改变 Markdown 内容来源的前提下，将站点升级为更接近 Fumadocs 的现代文档体验。

改造完成后，读者应能更快理解站点用途、定位指南、在文档树中切换内容，并清楚识别当前文章和文章目录。现有首页、新手路径、知识库、搜索、指南正文和 404 页面继续可用。

## 参考方案与边界

以 Fumadocs 的信息架构和视觉语言为主要参考：紧凑顶部栏、醒目的全局搜索入口、分组文档导航、正文与页内目录并列、清晰的边界和柔和背景层次。

本次不安装 `fumadocs-*` 包，也不复制其组件源码。现有 React 组件、内容索引和 `marked` 渲染链已经覆盖站点需求，直接替换框架只会增加构建风险。实现仅复用公开可观察的交互模式，并保留当前青绿色品牌识别。

## 页面结构

### 全局导航

顶部栏保留站点名称、首页、新手路径、知识库和 GitHub 入口。搜索改为更醒目的命令面板式入口，并显示键盘提示；移动端使用同一搜索入口，不增加第二套搜索实现。

### 首页

首页保留当前“五步完成第一篇结构化文献笔记”的主任务，但调整为文档产品式首屏：左侧强调价值与入口，右侧展示站点覆盖范围和可直接进入的核心文档。

下方继续展示新手路径、精选指南和知识库分类。卡片减少装饰，提高信息密度，并统一使用轻边框、柔和底色和短距离悬停反馈。

### 知识库与指南页

知识库首页采用分组列表，显示分类、标题与文档数量。

指南页桌面端维持三栏：左侧分组文档树、中间正文、右侧页内目录。左侧导航突出当前文章，右侧目录突出层级。移动端将文档树和目录合并到正文前的原生折叠区，保证键盘可用并避免额外状态管理。

### 搜索

保留当前浏览器本地搜索数据和结果页。顶部搜索入口直接聚焦搜索页输入框；不新增服务端索引、第三方搜索服务或快捷键依赖。搜索结果继续显示分类、标题和摘要。

## 视觉系统

- 使用更接近文档工具的中性浅色背景、白色内容面和细边框。
- 保留青绿色作为品牌强调色，不引入新的品牌色系。
- 正文继续优先使用系统中文字体；标题减少装饰性衬线字体，提升工具站一致性。
- 统一圆角、阴影、间距、正文宽度和代码块样式。
- 动效仅保留轻量悬停与焦点反馈，并尊重 `prefers-reduced-motion`。
- 不新增插画、图标包、暗色模式或主题切换。

## 组件与数据流

现有 `lib/content` 继续在构建时读取仓库公开 Markdown，输出分类、文档、目录和搜索数据。页面路由、URL 和公开文档范围保持不变。

改造集中在全局布局、首页、知识库列表、指南导航和样式文件。只有当重复结构已经存在于两个以上页面且明显影响维护时，才提取小型展示组件。

## 异常与兼容性

- Markdown 解析、404、站内链接验证和重复路径检测保持现状。
- 长标题、长代码行、宽表格和图片必须在窄屏下可滚动或缩放，不能撑破页面。
- 没有页内标题时隐藏右侧目录，不显示空框。
- JavaScript 不可用时，页面内容、链接和移动端原生折叠导航仍可访问；仅本地搜索交互不可用。

## 验证

- 运行现有站点测试，确认所有公开 Markdown、路由、搜索数据和站内链接仍通过。
- 运行生产构建，确认 Cloudflare Worker-compatible 输出成功。
- 检查首页、知识库、搜索、典型长文档和 404 页的桌面与移动端布局。
- 使用键盘访问导航、搜索入口、折叠区和正文链接，确认焦点可见。
- 部署到现有私有 Sites 项目后，验证首页和至少一篇指南可通过实际 URL 访问。

## 不在本次范围

不迁移到完整 Fumadocs、Docusaurus 或其他框架；不增加登录、评论、CMS、AI 问答、远程搜索、暗色模式、多语言、学习进度或分析脚本；不推送 GitHub。
