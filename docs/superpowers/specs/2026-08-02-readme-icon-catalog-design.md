# README 图标清单设计

## 目标

让根目录 `README.md` 成为网站内容类型的唯一显式来源，不再根据文件后缀猜测知识库或资源，并让文档中的本地资源链接始终指向当前站点。

## 清单格式

清单项统一写成：

```markdown
- 📄[Claude Code 指南](notes/agents/claude-code/claude-code.md)
- 🧾[CLAUDE.md 全局指令示范](notes/agents/claude-code/CLAUDE.md)
- 📺[安装视频](https://www.bilibili.com/video/example)
```

链接后不保留 `— 描述`。网站展示名称直接取链接文字，不读取 Markdown 一级标题，也不使用文件名覆盖链接文字。

## 类型规则

| 图标 | 类型名称 | 处理方式 |
| --- | --- | --- |
| 📄 | 文档 | 仅允许指向 `notes/` 下的本地 Markdown，生成知识库页面 |
| 📺 | 视频 | 生成资源卡片 |
| 🚀 | 启动工具 | 生成资源卡片；本地文本文件生成可复制源码页 |
| 🧾 | 源码与模板 | 生成资源卡片；本地文本文件生成可复制源码页 |
| 📊 | 数据分析 | 生成资源卡片 |
| ⚔️ | 排行榜 | 生成资源卡片 |
| 📰 | 新闻 | 生成资源卡片 |
| 📚 | 学习资料 | 生成资源卡片 |
| 🌐 | 网站 | 生成资源卡片 |

只有 `📄` 进入知识库。其他图标不受文件后缀影响，因此 `CLAUDE.md` 和 `AGENTS.md` 使用 `🧾` 后会作为资源源码展示。

清单中的链接项必须带受支持图标。缺少图标、未知图标、`📄` 指向外部链接或非 Markdown 文件时，构建应直接报错。

## 资源卡片

资源记录保存 README 图标、类型名称和链接文字。卡片左上角显示“图标 + 类型名称”，每种图标使用独立的浅色标签配色；卡片标题显示 README 链接文字。

源码详情页使用 README 链接文字作为页面标题，同时保留真实文件名供语言识别、复制按钮和下载语义使用。

## 站内链接

渲染知识库 Markdown 时：

- 指向 `📄` 条目的相对链接改写为 `/guides/...`。
- 指向本地源码或模板资源的相对链接改写为 `/resources/...`。
- 指向本地二进制下载资源的链接使用构建后的站内资源地址。
- 外部 URL 和页内锚点保持不变。
- 图片继续内嵌展示。

所有站内地址使用根相对路径，不硬编码 `notes.psiqaq.cn`，从而自动沿用当前访问域名。

## 验证

- README 中所有公开清单项符合图标协议且不含描述后缀。
- `CLAUDE.md`、`AGENTS.md` 不出现在知识库，能从资源页进入可复制详情页。
- `cc.bat`、`ccmac.sh`、`cclinux.sh` 以及上述 Markdown 模板在指南正文中链接到 `/resources/...`。
- 每种资源图标在卡片标签中保留图标和独立类型样式。
- 完整测试、构建和 lint 通过。
