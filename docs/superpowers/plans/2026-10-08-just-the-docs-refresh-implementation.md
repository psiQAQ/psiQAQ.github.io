## 页面与内容

根地址 `/` 直接展示知识库，`/library` 继续可用。知识库、指南、资源导航、资源详情、搜索和 404 页面共用文档布局。站点导航提供知识库和资源导航，搜索使用顶部搜索框。知识库正文从分类列表开始。

资源导航按 README 清单依次呈现七个主题：Agent 安装与配置、Agent 学习资料、LLM 参数汇总、LLM 评测排行榜、开发与模型工具、AI 新闻、AI 行业观察。“智能体”在资源页显示为“Agent 安装与配置”。Agent 学习资料包含入门与实践、原理与优化、MCP 市场三个分组。Models.dev 归入 LLM 参数汇总；Artificial Analysis 和 Arena AI 归入 LLM 评测排行榜。主题调整同步用于侧栏、面包屑和搜索。分类和分组标题分别以 `1.`、`1.1` 层级编号开头，侧栏采用对应编号，原章节锚点通过兼容入口保持可达。资源条目在所有屏幕尺寸均独占整行，桌面将类型和标题并排，手机允许分行。

知识库索引和资源侧栏共用分类、分组章节导航的样式，编号与各自正文标题对应。知识库按四个分类和七个分组定位指南列表。指南详情侧栏提供分类、分组、文章树；当前文章的上级目录默认展开。移动端根据当前页面展示相应导航。

Models.dev 以学习资料进入资源导航，完整正文在 `/resources/models/models-dev.md` 阅读，旧 `/guides/models/models-dev` 跳转到该页面。公开目录共 64 项：32 篇指南和 32 项资源，其中 34 篇内容按文章渲染。脚本与指令模板保留源码查看、章节定位和复制能力。

Markdown 正文和目录使用同一次解析的标题 ID。围栏内的井号注释不生成目录项；有效旧锚点、重复标题 `codex-2` 和模板的 `#user-interaction` 保持可达。

搜索按需加载静态索引，标题优先于分类和正文，显示命中片段。全部公开条目可搜索；围栏代码、模板/脚本全文及未列入公开目录的笔记不加入索引。顶部和独立搜索页支持加载失败后的重试。

PR 检查工作流只有读取权限。Pages 在上传前检查构建产物，并发布同一份 `dist/client`。导出同时保留平铺 HTML / RSC 和 46 个目录 `index.html`，覆盖普通网址、带尾部斜杠的网址及旧入口；目录入口与平铺页面内容一致。依赖版本及 lockfile 未修改。
