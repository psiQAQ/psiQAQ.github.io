# 领域文档

本仓库采用 single-context 布局，所有路径均相对仓库根目录。

## 探索代码前

- 若根目录 `GLOSSARY.md` 存在，先读取其中的领域术语。
- 若 `docs/adr/` 存在，读取与当前任务相关的架构决策。
- 文件尚不存在时，直接继续任务；
  由 domain-modeling 在术语或决策明确后按需创建。

## 使用约定

Issue 标题、设计建议、假设和测试名称中的领域概念，
沿用 `GLOSSARY.md` 定义的术语。

需要的概念尚未收录时，先判断是否符合项目已有用语；
确有缺口时，记录为后续 domain-modeling 的输入。

方案与已有 ADR 冲突时，指出具体 ADR、冲突内容及重新讨论的理由。
