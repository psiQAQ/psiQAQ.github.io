# Triage 标签映射

本地任务通过 `Status:` 行记录 triage 状态。

| 规范角色 | 本仓库状态名 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 需求明确，可交由 Agent 实施 |
| `ready-for-human` | `ready-for-human` | 需要人工实施 |
| `wontfix` | `wontfix` | 不予处理 |

Skill 提到某个角色时，使用表中对应的状态名。
以后可直接修改“本仓库状态名”列。
